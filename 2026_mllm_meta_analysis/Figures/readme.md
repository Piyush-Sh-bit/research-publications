# Figures

All 12 figures are generated by `code/run_analysis.py` (which calls `code/visualization.py` and
`code/visualization_robustness.py`) and are fully reproducible — re-running the pipeline regenerates
this folder from scratch with identical statistics. Filenames reflect generation order, which does
not always match the figure numbering used in the manuscript; the mapping is given below.

| File | Paper Figure | Description |
|---|---|---|
| `fig1_forest_plot.png` | Figure 2 | Forest plot of standardized effect sizes (mean z-scores) for all 21 MLLMs. Diamonds show individual model effects with 95% CIs; marker size is proportional to benchmark coverage. |
| `fig2_funnel_plot.png` | Figure 4 | Funnel plot of effect sizes against standard errors, used for the Egger's regression publication-bias assessment. Dashed line marks the pooled effect; shaded region is the pseudo-95% confidence funnel. |
| `fig3_correlation_heatmap.png` | Figure 5 | Spearman rank correlation matrix among the 7 visual reasoning benchmarks. Significance levels: \*p<0.05, \*\*p<0.01, \*\*\*p<0.001. Lower triangle only. |
| `fig4_scale_performance.png` | Figure 3 | Model scale (log10-transformed parameter count) vs. normalized benchmark score. Each point is one model-benchmark observation, colored by benchmark, with the meta-regression fit overlaid. |
| `fig5_subgroup_training.png` | *(not in manuscript)* | Subgroup forest plot by training strategy (RLHF / instruction-tuning / pretraining+alignment). Generated by the pipeline as a supplementary diagnostic but not included as a numbered figure in the final paper — the same comparison is reported as Table 3. |
| `fig6_radar_chart.png` | Figure 6 | Radar chart comparing normalized performance profiles of the top-6 ranked MLLMs across all available benchmarks. Radial distance is the normalized score (0–1). |
| `fig7_training_boxplot.png` | Figure 7 | Box plot of normalized benchmark scores by training strategy, with individual observations shown as jittered points. |
| `fig8_leave_one_out.png` | Figure 8 | Leave-one-out sensitivity analysis. Each row is the pooled effect size with the named model excluded; the dashed line is the full-sample estimate. |
| `fig9_galbraith_plot.png` | Figure 9 | Galbraith (radial) plot for heterogeneity assessment. Each point is a model; the solid line is the expected relationship at the pooled estimate. Used to identify the 14 of 21 models flagged as outliers (residual > 2 SD). |
| `fig10_pareto_frontier.png` | Figure 11 | Accuracy–efficiency Pareto frontier across all 21 models. Red points are Pareto-optimal (no other model is both more accurate and more efficient). TFLOPs are estimated from published values or parameter-count scaling heuristics. |
| `fig11_influence_diagnostics.png` | Figure 10 | Influence diagnostics: (a) DFBETAS per model against the |DFBETAS| > 2/√k threshold; (b) standardized residuals vs. leverage (hat values), with point size proportional to Cook's distance. |
| `fig12_pareto_open_weights.png` | Figure 12 | Open-weights-only accuracy–efficiency Pareto frontier (GPT-4V and Gemini-Pro-V excluded). Added in response to reviewer feedback questioning the reliability of TFLOP estimates for proprietary models — confirms the same 5 Pareto-optimal models hold without them. |

## Regenerating these figures

```bash
pip install -r requirements.txt
python code/run_analysis.py
```

This recreates every figure above (plus 13 results CSV tables) from the source data in
`code/data_collection.py` — no manual steps or external data files required.
